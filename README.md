# 📊 Dashboard de FIIs

Este projeto consiste em um dashboard interativo desenvolvido em **Python** utilizando **Streamlit**, com o objetivo de analisar e visualizar dados de Fundos Imobiliários (FIIs) de forma simples e intuitiva.

🔗 **Acesse a aplicação:**
https://proj-fiis-claytonmedeiros-python.streamlit.app/

---

## 🚀 Objetivo

O principal objetivo deste projeto é:

* Facilitar a visualização de dados de FIIs
* Permitir a análise rápida de preços e volume de negociação
* Servir como projeto prático de portfólio em análise de dados
* Demonstrar integração com APIs financeiras

---

## 🛠️ Tecnologias utilizadas

* Python
* Streamlit
* yfinance
* Pandas

---

## 📈 Funcionalidades

* Seleção de diferentes FIIs
* Exibição do preço atual do ativo
* Gráfico de preço de fechamento (últimos 6 meses)
* Visualização de volume negociado
* Tabela com dados recentes
* Interface simples e interativa
* Foto de perfil integrada ao dashboard

## ⚙️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Execute o projeto:

```bash
streamlit run app.py
```
